# THIS PROJECT IS NOT OFFICIAL!!!

## What is this?

Community Shaders modified for personal purposes to improve the look without using post-processing like Reshade. The code in the added lil.hlsl file is released under the zlib license because it may be used in other projects (including those outside Skyrim).

Just in case the original contributors are reading: If you like it, you can incorporate part or all of this version into original version.

## Changes
- Customized Tonemapping
- Widespread light bloom & modified DOF (not very well implemented)
- Directional light boost depending on color
- Highly visible eye specular
- Suppression of hair brightness
- Non-directional lights that are always applied
- Extended character lighting
- Water reflection adjustments
- Grass waving according to distance
- Modified volumetric lighting blending

## Download

You can download the latest version from [Releases](https://github.com/lilxyzw/skyrim-community-shaders/releases).
